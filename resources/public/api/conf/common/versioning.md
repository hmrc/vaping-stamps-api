The Vaping Duty Stamps - Approval Status Check API follows a simplified variation of the semantic versioning to manage changes and maintain compatibility for API consumers.

A new API version is introduced only on occasions when a backward-incompatible change occurs. Such changes may require revisions to existing integrations.

Examples of backward-incompatible changes include:
  - removing existing fields
  - modifying endpoint behaviour such that it impacts existing consumers

Backward-compatible enhancements, such as additional response attributes may be released without a major version change.

Users should test and validate against the appropriate API version before deploying to production environments.
