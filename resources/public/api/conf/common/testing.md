The Vaping Duty Stamps - Approval Status Check API can be tested using the [HMRC Developer sandbox](https://developer.service.hmrc.gov.uk/api-documentation/docs/testing).

The HMRC Developer sandbox provides a test environment for developers to validate integrations before deployment in an environment that replicates the behaviour of the production platform.

The sandbox environment is capable of:
  - verifying API integrations and connectivity
  - testing request and response processes
  - validating data flows, error-handling and exception scenarios


**Endpoint availability**

Until this API is available in the production environment, the endpoint will be identified with the label **[Test only]**. This indicates that the endpoint is available purely for Test purposes only and cannot be used for live operational purposes.

*Note*

The sandbox data and responses are intended exclusively for testing purposes.

Information returned by the sandbox environment must not be used for any operational decision-making.
